# PART 1: HOW TO PLAY

## 1. ストーリー

西暦2088年。

巨大都市の上空に建設された立体サーキットでは、ボディも道路も光の線だけで形作られた新競技「WIRE DRIFT」が人気を集めていた。

ルールは単純。2台のマシンが同じリングへ入り、先に3周すれば勝利。

しかし、コース上にはブーストエネルギーを供給するアクティブゲートが存在する。ゲートを取るためには最速ラインを捨て、相手の進路へ飛び込まなければならない。接近した2台はドリフトタックルで互いを押し出し、わずかな判断の遅れが勝敗を変える。

赤いマシンと青いマシン。

静かなワイヤーフレームの都市で、3周だけの戦いが始まる。

## 2. ゲームの目的

相手より先にコースを3周してください。

- 1 PLAYERでは、赤いP1マシンを操作して青いCPUマシンと対戦します。
- 2 PLAYERSでは、1台のX68000で2人同時に対戦します。
- 同じ物理フレームで両車が3周した場合はDEAD HEATです。
- レース終了後はリザルト画面を表示し、約5秒後にタイトルへ戻ります。

## 3. ゲームの始め方

### タイトル画面

```text
             1 PLAYER  CPU LEVEL 3
                    2 PLAYERS

                    SPACE START
```

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| モード選択 | `W` / `S` またはカーソル上下 | どちらかのパッドの上下 |
| CPU LEVEL変更 | `A` / `D` またはカーソル左右 | どちらかのパッドの左右 |
| 決定 | `SPACE` | ボタン1 |

CPU LEVELは1 PLAYERで使用します。初期設定はLEVEL 3です。

タイトル画面でしばらく操作しないと、DEMO REPLAYが始まります。いずれかのキーまたはパッドを操作するとタイトルへ戻ります。

モードを決定すると、次の順番でレースへ進みます。

```text
TITLE  ->  SELECT COURSE  ->  HOW TO PLAY  ->  RACE
```

### HOW TO PLAY画面

操作方法を確認したら、`SPACE`またはパッドのボタン1でレースを始めます。`ESC`でコース選択へ戻ります。

### スタートシーケンス

カメラ演出の後、次の順番でスタートします。

```text
READY  ->  3  ->  2  ->  1  ->  START
```

STARTまではマシンが動きません。ブーストはカウントダウン中に一度ボタンを離してから使用してください。押したまま待っても先行ブーストにはなりません。

## 4. コース選択

タイトルでモードを決定すると、回転するワイヤーフレームのコース選択画面へ進みます。

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| コース変更 | `A` / `D` またはカーソル左右 | どちらかのパッドの左右 |
| 決定 | `SPACE` | ボタン1 |
| タイトルへ戻る | `ESC` | - |

| コース | 形状 | 特徴 |
|---|---|---|
| `RING` | 均整の取れた円形リング | 基本操作、ゲート争奪、タックルを学びやすい標準コース |
| `OVAL` | 横に広い高速オーバル | 長い加速区間を意識し、ブーストをまとめて使いやすいコース |
| `PULSE` | 3つの頂点を持つ脈動形状 | ライン変化を早めに読み、ゲートへの進路を組み立てるテクニカルコース |

コースによって形とレースラインは変わりますが、最高速度、加速度、ブースト容量、ゲート報酬、3周の勝利条件は共通です。

## 6. レース画面の見方

```text
 P1 LAP 1 OF 3                     CPU LAP 1 OF 3
 BOOST ======..                    BOOST ====....

             ACTIVE GATE LINE

          RED CAR          BLUE CAR

        INNER RAIL        OUTER RAIL
```

| 表示 | 意味 |
|---|---|
| `P1 LAP` | PLAYER 1の周回数 |
| `P2 LAP` | PLAYER 2の周回数 |
| `CPU LAP` | 1 PLAYER時のCPU周回数 |
| `BOOST` | 8段階のブースト残量 |
| 明るい車体 | ブースト使用中 |
| コースを横切る短い線 | 現在取得できるアクティブゲート |

## 7. ゲームルール

### 3 LAPS TO WIN

先に3周したマシンが勝者です。周回数はスタートラインを正方向へ通過すると増えます。

### DEAD HEAT

固定20 Hzの同じ物理更新で両車が3周へ到達した場合は引き分けです。リザルト画面にはDEAD HEATと表示されます。

### RESULT

勝者、両車の周回数を表示します。ゴール時に押していたキーやパッドを一度離すまで、リザルトの自動復帰時間は進みません。

## 8. マシンとコースの機能

### BOOST

ブーストボタンを押している間、通常最高速度を超えて強く加速します。使用中は車体が明るくなり、HUDのゲージが減ります。

### ACTIVE GATE

コース上には3つのゲートがあります。各ゲートは内側、中央、外側のどれか1レーンで有効です。

先に正しいレーンを通過したマシンはブーストを回復します。取得されたゲートは約3秒消灯し、次は別のレーンで点灯します。

### DRIFT TACKLE

相手へ向かって横移動しながら接触すると、相手をレーン外側または内側へ押し出します。攻撃側も少し減速するため、むやみに接触すると逆に不利になります。

壁際へ押し出されたマシンは、通常より大きく速度を失います。

### CATCH-UP BOOST

差が一定以上開くと、後続車のブーストが少しずつ回復します。速度そのものは自動で上がりません。回復したブーストをどこで使うかが逆転の鍵です。

## 9. CPU LEVEL

| LEVEL | 特徴 | おすすめ |
|---:|---|---|
| 1 | 判断が遅く、ゲート狙いに大きな誤差があります | 初めて遊ぶ方 |
| 2 | 短いブーストを控えめに使います | 操作練習 |
| 3 | 標準的な反応とブースト制御です | 通常プレイ |
| 4 | 素早くゲートを狙い、長めにブーストします | 上級者 |
| 5 | 判断が速く、狙いも正確です | チャレンジ |

CPUは大きく先行するとブーストを控えます。どのLEVELでもPLAYER 1と同じ車両物理、速度上限、ゲート、追走回復ルールを使用します。

# PART 2: RACING GUIDE

## 10. コース別攻略

### RING: 基本を崩さない

内外の距離差が読みやすい標準コースです。中央から次のゲートを確認し、接近したときだけタックルを狙う走りが安定します。

### OVAL: 加速区間をつなぐ

横長の区間では大きな速度差を作りやすくなります。ゲート争奪でブーストを使い切らず、相手とラインが離れた区間で長めの加速へつなげてください。

### PULSE: 1つ先の頂点を見る

3つの頂点でコース形状の変化が強く見えます。現在位置だけを追わず、次の頂点とゲートのレーンを同時に見て早めに横移動してください。

## 11. 基本テクニック

### 最初は中央を走る

START直後は中央付近を維持すると、内側と外側のどちらにゲートが出ても対応しやすくなります。

### 相手ではなく次のゲートを見る

現在の位置だけでなく、次に通過するゲートのレーンを早めに確認してください。直前の大きな横移動は速度と位置取りを失いやすくなります。

### ブレーキはライン調整に使う

ブレーキは停止するためだけの操作ではありません。相手の後ろへ入り直す、ゲート通過のタイミングをずらす、タックルを空振りさせるためにも使えます。

## 12. ブースト攻略

### 押し続けない

ブーストは通常最高速度を超えるための切り札です。長く押し続けるより、コーナー出口やゲート取得直後に短く使う方が効率的です。

### ゲート前に少し残す

ゲートへ向かう横移動やタックルで速度を失ったとき、残しておいたブーストが再加速に役立ちます。

### 後続時はゲージを見る

後続車は差に応じてブーストが回復します。ゲージが増え始めたら、満タンまで待つよりも短い加速を繰り返して差を縮める方法が有効です。

## 13. アクティブゲート攻略

### 3つ先ではなく1つ先を見る

すべてのゲートを取ろうとすると大きな蛇行になります。最も近いゲートが遠いレーンにある場合は、次のゲートへ備える判断も必要です。

### 相手と同じレーンへ入る

相手がゲートを狙っているときは、同じレーンへ入ることでドリフトタックルの機会が生まれます。ただし正面から接触するだけでは両者が減速します。

### 消灯中は最短ラインへ戻る

ゲート取得後は約3秒間消灯します。その間はゲートを待たず、次の点灯位置へ向けて中央へ戻ると安全です。

## 14. ドリフトタックル攻略

### 相手方向へ入力する

接触しているだけでは強いタックルになりません。相手が外側にいるなら外側、内側にいるなら内側へドリフトしながら接触してください。

### 壁際が最大のチャンス

相手をコース端へ押し込むと追加減速が発生します。ゲートを奪うだけでなく、その後のブーストで一気に離れる機会になります。

### 同時攻撃に注意

両車が互いへドリフトしていると双方が大きく減速します。自分が先行している場合は、無理に打ち合わずレーンを譲る判断も重要です。

## 15. 追いつくための戦い方

### 差が開いてもブーストを空にしない

後続回復があるため、レースは最後まで続きます。回復したブーストをすぐ全部使わず、ゲート争奪と再加速のために分けて使ってください。

### CPUが先行したらゲートを1つ捨てる

CPUを追って大きく蛇行すると、さらに差が広がります。遠いゲートを捨て、短いラインとブーストで距離を縮めてから次のゲートを争います。

### 接近後は相手の内側を取る

内側に位置すると、相手を外へ押し出すタックルを狙いやすくなります。追いついた直後が最大の逆転機会です。

## 16. CPU攻略

### LEVEL 1-2

CPUのゲート判断には遅れと誤差があります。先に目的レーンへ入り、無理なタックルをせずゲートを確実に取ってください。

### LEVEL 3

CPUは標準的な間隔でブーストを使います。CPUのバースト終了後に自分のブーストを使うと、少ない消費で差を縮められます。

### LEVEL 4-5

正面から速度だけで競うと不利になります。遠いゲートを捨てる判断、壁際のタックル、後続ブースト回復を組み合わせてください。

## 17. 2 PLAYER攻略

### キーの押しすぎに注意

同時押しの多い場面では、使用するキーボードによって入力できる組み合わせが異なる場合があります。可能であれば2台のゲームパッドを使用してください。

### 相手のゲージを見る

相手のブーストが少ないときはゲートを捨てても大きな損になりません。反対に相手が満タンなら、ゲートよりタックルで速度を落とす方が有効な場合があります。

### 最終周まで勝負は終わらない

先行車はゲートを守り、後続車は回復ブーストとタックルで接近します。同じ更新でゴールすればDEAD HEATです。最後のスタートラインまで操作を続けてください。
