# Wire Drift Racers 仕様書

## 1) 画面イメージ（ローカル2プレイ）

```text

│ Wire Drift Racers                                    2P OFFLINE │
│ Lap   P1: 00:42  18pt  v=4.2   P2: 00:38  18pt  v=4.8      │
│                                                              │
│                         （Wireframe 3Dコース）               │
│         /------------------------------\                       │
│        /                                \                      │
│       /   ◎P1    ○ゲート     ◎P2       \                     │
│      /                                  \                    │
│     /------------------------------------\                   │
│                                                              │
│ P1: W 加速 / S 減速 / A,D ドリフト / Q ブースト / E ブレーキ     │
│ P2: ↑ 加速 / ↓ 減速 / ←,→ ドリフト / N ブースト / M ブレーキ    │
```

- 中央は固定の3D斜め俯瞰（ダウンタウン視点）
- コース、壁、ランプ、ゲートは全て線（ワイヤ）だけで描画

## 2) コア仕様（オフライン前提）

1. 対戦形式
   - 1台のPCで2プレイヤー同時対戦（キー入力別々）
2. 勝敗
   - 先に3周先取、または90秒タイムトライアル + 先着
3. フィールド
   - 3Dトーラス（円形リング）を基準にしたワイヤフレームコース
   - 内壁/外壁の幅でトラックレールを表現
4. 操作
   - アクセル/ブレーキで加速/減速
   - 左右キーでレーン移動＋ドリフト（大きめに横移動）
   - ブーストは短時間だけ加速度増加（スタミナ制）
5. 物理
   - 速度は上限あり
   - 壁への接触で反発（速度低下）
   - 車体同士接触で同量デクリメント・ノックバック
6. 見た目
   - 面なし（完全ワイヤフレーム）
   - 背景グリッド + 輝くライン + 影無し
7. サウンド
   - 必須3種だけ（加速、壁接触、ゴール）
8. 難易度モード
   - EASY: 壁摩擦少、BOOST多
   - HARD: 壁反発強、BOOST回数少

## 3) 画面構成

1. メインゲーム画面
   - 上部HUD: スコア、ラップ、速度、残り時間
   - 中央: 3Dワイヤーフィールド
   - 下部: 入力チート防止のための簡易ヒント
2. ポーズ/リザルト画面
   - 1回分のラップ比較表示
   - 再戦/終了ボタン

## 4) 最短で実装するデータ設計

1. car
   - angle（コース上の進行位）、offset（壁間の左右位置）、speed、boost、lap
2. track
   - center(t), wall(t, offset) の関数で生成（配列不要）
3. camera
   - 固定位置 + 回転行列（簡易3D→2D投影）
4. gameState
   - frame, winner, time, running

## 5) 短いソースコード方針（約140〜180行）

1. 3D投影は1関数（project(p)）
2. コースは固定関数で点列生成（trackPoint(t, lane)）
3. 描画は1フレームで
   - 内壁/外壁線を120分割描画
   - ゲートを数個
   - 車体（2〜3本ライン）を描画
4. 物理更新は1関数
   - 入力→速度→角度/レーン→壁当たり判定→ラップ更新
5. 画面表示はHUDのみ

## 6) 対戦ゲーム性

円形コースを周回するだけの展開を避けるため、車線選択、追走、車体接触を組み合わせた対戦要素を導入する。コース形状と描画量を大きく増やさず、2プレイヤー間で継続的な駆け引きが発生することを優先する。

### 6.1 初期実装する対戦要素

1. アクティブゲート争奪
   - コース上に3〜4か所のブーストゲートを配置する
   - 各ゲートは内側、中央、外側のいずれか1レーンだけ有効になる
   - 有効レーンは一定周期またはゲート取得後に変更する
   - 先に通過したプレイヤーだけがブーストエネルギーを獲得する
   - 取得後のゲートは一定時間消灯し、連続取得を防止する
   - ゲートは少数のワイヤフレーム線で表現する
2. ドリフトタックル
   - 通常接触では両車を少し減速させる
   - 横方向へドリフト中の側面接触では、相手を外側へ大きくノックバックさせる
   - 攻撃側も少し速度を失い、無条件に有利にならないようにする
   - 既存の左右操作を使用し、攻撃専用キーは追加しない
3. スリップストリーム
   - 後続車が先行車の後方かつ近いレーンを走るとブーストエネルギーが増加する
   - 判定にはコース上の角度差、レーン差、前後関係を使用する
   - 追走状態はHUDまたは車体色の変化で示す
   - 後続車が追いつきやすくなることで、一方的な展開を抑える

### 6.2 レーン特性

- 内側レーンは走行距離が短い代わりに最高速度を低くする
- 中央レーンは距離、最高速度、操作性を標準とする
- 外側レーンは走行距離が長い代わりに最高速度とブースト効率を高くする
- ゲート位置とレーン特性を組み合わせ、常に同じレーンを走ることが最適にならないようにする

### 6.3 基本的な対戦の流れ

1. 後続車がスリップストリームで先行車へ接近する
2. 次のアクティブゲートに合わせて両車がレーンを変更する
3. ドリフトタックルでゲートの進入位置を奪い合う
4. ゲートを取得した車がブーストで抜け出す
5. 以上の攻防を繰り返し、先に3周したプレイヤーが勝利する

### 6.4 将来追加を検討する要素

- 一定周期で通行可能レーンが変化する可動ブロッカー
- ブースト中の接触によるエネルギー奪取
- 後方からの追い越しに対する短時間の加速ボーナス
- 1周に1回だけ設置できる減速用ワイヤートラップ
- 相手を一定回数壁へ押し出すことでも勝利できるノックアウトルール
- 先頭車または特定区間を対象にする追跡ターゲット

弾や設置物は、消去後の路面修復、当たり判定、ダブルバッファごとの描画状態を複雑にするため、初期実装には含めない。
