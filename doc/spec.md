# Wire Drift Racers 仕様書

- 中央は固定の3D斜め俯瞰（ダウンタウン視点）
- コース、壁、ランプ、ゲートは全て線（ワイヤ）だけで描画

## 2) コア仕様（オフライン前提）

1. 対戦形式
   - 1台のPCで2プレイヤー同時対戦（キー入力別々）
2. 勝敗
   - 先に3周先取、または90秒タイムトライアル + 先着
3. フィールド
   - 3Dトーラス（円形リング）を基準にしたワイヤフレームコース
   - 内壁/外壁の幅でトラックレールを表現
4. 操作
   - アクセル/ブレーキで加速/減速
   - 左右キーでレーン移動＋ドリフト（大きめに横移動）
   - ブーストは短時間だけ加速度増加（スタミナ制）
5. 物理
   - 速度は上限あり
   - 壁への接触で反発（速度低下）
   - 車体同士接触で同量デクリメント・ノックバック
6. 見た目
   - 面なし（完全ワイヤフレーム）
   - 背景グリッド + 輝くライン + 影無し
7. サウンド
   - 必須3種だけ（加速、壁接触、ゴール）
8. 難易度モード
   - EASY: 壁摩擦少、BOOST多
   - HARD: 壁反発強、BOOST回数少

## 3) 画面構成

1. メインゲーム画面
   - 上部HUD: スコア、ラップ、速度、残り時間
   - 中央: 3Dワイヤーフィールド
   - 下部: 入力チート防止のための簡易ヒント
2. ポーズ/リザルト画面
   - 1回分のラップ比較表示
   - 再戦/終了ボタン

## 4) 最短で実装するデータ設計

1. car
   - angle（コース上の進行位）、offset（壁間の左右位置）、speed、boost、lap
2. track
   - center(t), wall(t, offset) の関数で生成（配列不要）
3. camera
   - 固定位置 + 回転行列（簡易3D→2D投影）
4. gameState
   - frame, winner, time, running

## 5) 短いソースコード方針（約140〜180行）

1. 3D投影は1関数（project(p)）
2. コースは固定関数で点列生成（trackPoint(t, lane)）
3. 描画は1フレームで
   - 内壁/外壁線を120分割描画
   - ゲートを数個
   - 車体（2〜3本ライン）を描画
4. 物理更新は1関数
   - 入力→速度→角度/レーン→壁当たり判定→ラップ更新
5. 画面表示はHUDのみ
